# Powered by Hive-r

* Flappy Fish game using HTML, CSS, and JavaScript

## Overview

Flappy Fish is a simple browser-based game inspired by Flappy Bird. Guide your fish through gaps in the pipes and try to achieve the highest score possible!

## Features

- Responsive design for desktop and mobile browsers
- Smooth animations and controls
- Score tracking and high score saving
- Easy to customize graphics and sounds

## How to Play

1. Open `hive-r.github.io/Shog-oy-finalexam-fluffyfish` in your web browser.
2. Click or press the spacebar to make the fish swim upward.
3. Avoid hitting the pipes or the ground.
4. Try to beat your high score!
